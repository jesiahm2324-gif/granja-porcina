# Mi Granja Porcina

App de cría y engorde de cerdos: preñez de cerdas, inventario por lotes, estructura de costos y estado de resultados.

- Los datos se guardan en el teléfono de cada usuario. Hagan respaldo desde Ajustes.
- El acceso es con código de invitación creado en el Generador de Claves (no se sube a este repositorio).

Créditos: cerdito de Fluent Emoji de Microsoft (MIT). Letra del logo: Barlow Semi Condensed (OFL).
